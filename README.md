# Personal Knowledge Docs

This repo is a documentation site hosting a collection of programming-related knowledge, techniques and opinions I've gathered through my professional and personal projects. It is meant to be both a way for me to explore my thoughts and also a reference for future me to look back upon and challenge these ideas.

It is focused mostly on FE and mobile development with an emphasis on techniques for implementing clean and scalable architectures. For anyone actually reading through the docs, you'll notice said architecture is heavily influences by traditionally more BE concepts such as Dependency Injection, Ports & Adapters, Domain Driven Design, and more. I also emphasize maintaining an acyclical DAG dependency chain across modules since I believe it makes following code easier and also makes it easier to extend and/or throw away.

The docs are mainly split into two groups: general knowledge (anything top level) and project-specific knowledge (anything nested under /projects). I currently have only reference [dokseo](https://github.com/jerhage/dokseo), a local-first reading application for Japanese and Korean language learners with built in OCR and [Rifty](https://github.com/jerhage/Rifty), a Riftbound Companion App (still waiting on approval from Riot before publishing).

I also have ambitions to translate everything into Korean for fun but... that may take awhile.
